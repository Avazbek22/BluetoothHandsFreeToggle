BluetoothHandsFreeToggle은 Windows가 Bluetooth 클래식 헤드셋을 저품질 HFP 통화 모드로 남겨둘 때 정상적인 스테레오 재생을 복원합니다.

모드:
 - 상태 확인: 지원되는 HFP 서비스와 백업 상태를 읽습니다. 변경 사항은 없습니다.
 - 소프트 리셋: 시작 유형을 변경하지 않고 활성 HFP 서비스만 재시작합니다.
   앱이 마이크 사용을 중단한 후에도 통화 모드가 활성 상태로 남아 있을 때 사용하세요.
 - 하드 모드: 고품질 A2DP 재생을 강제하기 위해 시스템 전체에서 HFP를 중지하고 비활성화합니다.
   하드 모드가 활성화된 동안 블루투스 헤드셋 마이크는 사용할 수 없습니다.
 - 복원: 하드 모드가 저장한 시작 시점과 실행/중지 상태를 정확히 반환합니다.
   백업이 없는 경우 수동 + 실행 복구 기본값을 사용합니다.
 - 언어 변경: 전체 언어 목록을 열고 선택한 언어를 기억합니다.
   첫 실행 시, 인터페이스 언어는 Windows 설정에서 감지됩니다.

중요한 제한 사항:
 - Bluetooth Classic은 HFP 마이크를 활성화한 상태에서는 A2DP 수준의 재생을 제공할 수 없습니다.
   소프트 리셋은 멈춘 세션을 지울 수 있지만, 이 프로토콜 제한은 제거할 수 없습니다.

안전:
 - 상태 확인에는 관리자 권한이 필요하지 않습니다.
 - 서비스 변경에는 관리자 권한이 필요합니다.
 - 하드 모드는 서비스 구성을 변경하기 전에 백업을 만듭니다.
 - 하드 모드를 반복 실행해도 첫 번째 원래 상태 백업이 유지됩니다.
 - 복원 시 복구의 일부라도 실패하면 백업을 유지합니다.
 - 하드 모드는 이 Windows 설치에서 모든 블루투스 클래식 헤드셋에 영향을 줍니다.

문제 해결:
 - 소프트 리셋을 수행하기 전에 게임, 브라우저, 음성 채팅 및 녹음 앱을 닫으십시오.
 - 소프트 리셋으로 스테레오 품질이 복원되지 않으면 하드 모드를 사용하세요.
 - 하드 모드가 헤드셋 마이크를 비활성화했다면 이전 상태로 복원하려면 복원(복원)을 사용하세요.
 - 앱이 이전 오디오 경로를 캐시한 경우, 작업 후 헤드셋을 재연결하거나 오디오 재생을 재시작하십시오.
