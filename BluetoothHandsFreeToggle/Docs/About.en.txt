BluetoothHandsFreeToggle is a Windows utility for recovering high-quality Bluetooth Classic headset playback.

Features:
 - Safe Soft reset that keeps the HFP microphone available
 - Hard mode that prioritizes playback quality
 - Backup-based restoration of the original service state
 - Interface localized into 30 widely used languages
 - Focused interactive console menu

The utility manages a conservative list of Windows HFP services. It does not uninstall drivers, remove Bluetooth pairings or change headset firmware.
