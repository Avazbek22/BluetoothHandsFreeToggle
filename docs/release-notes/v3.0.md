**BluetoothHandsFreeToggle is now StereoKeeper.** Same free, open-source app with a new name, a new icon and a tray panel instead of the console.

StereoKeeper fixes Bluetooth headphones that suddenly sound muffled and mono on Windows because a game, Discord or a browser turned on the headset microphone and Windows switched them to call mode (HFP).

![StereoKeeper tray panel](https://raw.githubusercontent.com/Avazbek22/StereoKeeper/master/.github/assets/app-panel.png)

## What's new

- **Tray app.** Click the icon to see whether the headphones play in stereo or are in call mode, and which apps hold the headset microphone. The icon's dot shows the same at a glance.
- **Bring back stereo** (was Soft reset) ends call mode with one click. Windows settings stay as they are and the headset microphone keeps working.
- **Always stereo** (was Hard mode) is now a switch. It keeps the headphones out of call mode while you use another microphone, and turning it off puts Windows back exactly as it was.
- Every action shows its steps in plain words while Windows restarts the services, and explains what to do if something goes wrong.
- Optional Windows notifications when the headphones switch to call mode or an app turns on their microphone.
- Settings: start with Windows, language, notifications.
- Built-in help in all 30 languages: why the sound gets bad, what each button changes and how to undo everything before uninstalling.
- **Copy info for the developer** in Settings copies the app and Windows version, the headphone mode and the error log for a bug report, with your user folder hidden.
- The panel runs without administrator rights. Windows asks for permission only when you click Bring back stereo or flip Always stereo.
- If the panel ever cannot start, Windows shows the reason, and with Always stereo on it offers to put Windows back first.
- **Light on the PC.** About 25 MB of memory in the tray, near-zero CPU and no GPU use. The download shrank from 42 MB in 2.2 to 21 MB.

## Removed

- The console menu and the command-line mode.
- The WinGet command `bhft`. After the update the command is `stereokeeper`.

## Updating from 2.x

- The WinGet package ID stays the same: `winget upgrade OlimoffDev.BluetoothHandsFreeToggle`.
- If Hard mode was on, StereoKeeper shows Always stereo as on, and turning it off restores the services saved by 2.x.
- Your language choice is kept.

- Administrator permission only for Bring back stereo and Always stereo
